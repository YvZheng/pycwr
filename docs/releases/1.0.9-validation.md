# Validation for pycwr 1.0.9

The frozen source and installed compiled wheel were checked on macOS Apple silicon with CPython 3.12, NumPy 2.2.6, and the full optional dependencies. The automated suite contains 293 tests: 243 passed and 50 sample-dependent or optional slow tests were skipped. No tests failed.

## Function checks

The suite plus three real WSR98D volumes executed all **474 public Python functions, methods, and constructors** identified by the AST inventory. Python statement coverage is **87.49% (8235/9413)**. This measures execution; it does not mean every branch, possible input, or vendor file variant is proven correct. Cython is checked separately through numerical tests and an assertion that the installed module is a compiled extension.

Synthetic contracts verify expected values, dimensions, units, masks, errors, and compatibility aliases. Plot checks render the figures and prohibit map-data downloads. Issue #60 uses fresh Python processes to exercise missing and installed Py-ART colormap registries in both import orders. The same suite runs against each installed wheel in release CI.

## Real radar volumes

Three WSR98D files (Haikou 2019-08-28 and sites Z9513/Z9515 on 2026-05-20) were tested through CR, CAPPI, 3D CAPPI, ET, VIL, Cartesian/geographic sections, RHI, QC, and HID.

The export checks include 261 WSR98D sweep/field comparisons, 162 NEXRAD MSG31 and 81 MSG1 comparisons, three CfRadial round trips, three xradar NetCDF writes, and web-viewer metadata/PPI/section requests. WSR98D was inspected at the binary-header level and read back with pycwr. NEXRAD and CfRadial were read independently with Py-ART. Tests retain the original moment quantization scale and check missing values and range coordinates.

CC, SC, SAB, and PA use synthetic binary fixtures, including compression, truncated input, unnamed streams, and split sweeps. Real vendor variants of these four formats remain outside the validation evidence.

## Reproduce

Install the full test dependencies and run from a clean checkout:

```bash
python -m pip install -r requirements-full.txt coverage PyYAML
python -m coverage run -m unittest discover -s test -p 'test_*.py'
python -m coverage combine
python -m coverage json --show-contexts -o coverage.json
python scripts/audit_public_api.py coverage.json --output public-api-coverage.json
```

The local coverage total additionally includes the three non-distributed real volumes described above; a checkout without those files will have a different statement total. All public function contracts use synthetic fixtures and do not require those radar volumes.

Release CI builds CPython 3.9–3.12 wheels for Linux x86_64, Windows x64, macOS Intel, and macOS Apple silicon. Publication is gated on installed-wheel tests, compiled-extension loading, wheel tag/content checks, and package metadata checks. The release includes SHA-256 checksums. Actual platform run results are recorded in [GitHub Actions](https://github.com/YvZheng/pycwr/actions).
